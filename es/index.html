    Drops vs Web Assets

    Drops

    ¿Necesitas una URL rápida?

    Capturas, Slack, PRs. Pégala, copia el enlace, caduca cuando tú elijas.

    Web Assets

    ¿Estás construyendo una app?

    Logos, heroes, favicons y fuentes con URLs /m/… que no cambian al sustituir el archivo.

    Todo lo que tu sitio hecho con IA necesita. Nada que no.

    Imágenes, SVG, iconos y fuentes web: validados, versionados y servidos desde URLs estables.

    • Raster: JPEG, PNG, WebP, GIF, AVIF

    • Fuentes: WOFF, WOFF2

    Preguntas frecuentes

    ¿Qué diferencia hay entre Drops y Web Assets?

    Los Drops son enlaces temporales para capturas y chats. Los Web Assets son archivos permanentes de la aplicación — logos, heroes, favicons, SVG y fuentes — con URLs /m/… que no cambian al sustituir el archivo.

    ¿Hace falta crear una cuenta?

    No para un Drop. Pegas y compartes sin registro. Los Web Assets necesitan un proyecto con sesión para que los alias y versiones sean tuyos.

    ¿Cuánto tiempo está disponible la imagen de un Drop?

    El tiempo que elijas: 1 hora, 24 horas, 7 días o 30 días, con 7 días por defecto. Con Drops Pro el Drop puede durar hasta 180 días. Los Web Assets se quedan hasta que los sustituyas o borres. Una suscripción de Web Assets no cambia la caducidad ni las contraseñas de los Drops.
