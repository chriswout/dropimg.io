    FAQ

    What is the difference between Drops and Web Assets?

    Drops are temporary image links for screenshots and chat. Web Assets are permanent application files — logos, heroes, favicons, SVGs, and web fonts — with stable /m/… URLs that stay put when you replace the file.

    Do I need an account?

    Not for a Drop. Paste and share without signing up. Web Assets need a signed-in project so aliases and versions stay owned by you.

    How long do Drop images stay online?

    As long as you choose: 1 hour, 24 hours, 7 days, or 30 days, with 7 days selected by default. Drops Pro links can last up to 180 days. Web Assets stay until you replace or delete them. A Web Assets subscription does not change Drop expiry or password features.
