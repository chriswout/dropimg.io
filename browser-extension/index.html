What it does

  1. Click the toolbar icon, choose Visible or Region, then Capture.
  2. Press Alt+Shift+D anytime for a silent visible capture — link copied, toast on the page.
  3. Uploads go to dropimg.io; the share URL is copied automatically.
  4. Recent drops (last 10) stay on your device — copy, open, or delete.

Capture modes

  • Visible — what you see in the tab.
  • Region — draw a rectangle on the page, then upload the crop.

Install

Chrome Web Store and Microsoft Edge Add-ons listings will appear here once published. Until then, developers can load the unpacked build from the open-source repository (see the extension README).

Store links: coming soon — same Manifest V3 package for Chrome and Edge.

Permissions

  • activeTab — capture the tab you invoke on.
  • scripting — temporary region-selection overlay on that tab.
  • storage — local recent drops (not synced to an account).
  • offscreen + notifications — clipboard write and fallback notice for silent / region completion.
  • Host access to dropimg.io — upload screenshots to our API.

We do not sell data or require an account. Uploads follow the same rules as the website: metadata stripping when supported, and the expiry you choose. Details are in the Privacy Policy.

What it is not

No annotation tools, OCR, AI analysis, or cloud sync. One job: capture → link. Signing in is optional and only adds history, longer links, and larger uploads.
