Upload a screenshot to a URL

dropimg.io is a free ShareX image host: import one custom uploader file, keep capturing the way you already do, and get a temporary URL. No account required. The public config is anonymous; an account config attaches uploads to My drops.

Custom uploader on GitHub

One-click install

  1. Download dropimg.sxcu and double-click it. ShareX activates the custom uploader automatically. You can also Import it under Destinations → Custom uploader.
  2. Set dropimg.io as the image uploader destination.
  3. Capture as usual. ShareX uploads the screenshot and copies the temporary URL.

Anonymous vs account

Anonymous: the public .sxcu. No token, no sign-in, 10 MB, 7-day default (or 1h, 24h, 30d). Uploads are not listed in an account. This is the free ShareX image host most people want.

Account: sign in, open Integrations, and click Create ShareX config. Download dropimg-sharex.sxcu immediately — the token is shown once. Those uploads appear in My drops and follow your plan’s expiry options. Never commit that file.

Privacy and expiry

dropimg.io is a temporary ShareX uploader, not a permanent archive. Links default to 7 days and then go away. The public config can send expiry=1h, 24h, 7d, or 30d. Pro account configs also accept 90d and 180d. Image passwords are not in the ShareX config. See the privacy policy for what is stored.

If you lose an account config

Revoke the old token on Integrations and create a new config. DropIMG cannot regenerate a previous token or .sxcu.

Source on GitHub

The anonymous custom uploader lives at github.com/chriswout/dropimg-sharex — .sxcu, screenshots, and the same install steps. ShareX users who browse GitHub can clone or download the file from there. This page is the canonical setup URL.

ShareX questions

Is this a free ShareX image host?

Yes. The anonymous custom uploader needs no account. Screenshots upload to dropimg.io and return a temporary URL. Max 10 MB. SVG is not accepted.

How do I add the ShareX custom uploader?

Download dropimg.sxcu and double-click it. ShareX imports the destination automatically. Or Import it from Destinations → Custom uploader, then set dropimg.io as the image uploader.

Do I need an account to upload a ShareX screenshot to a URL?

No. The public .sxcu is anonymous. Sign in only if you want uploads in My drops, or longer Pro expiries (90 or 180 days).

How long do temporary ShareX links last?

The public config sends expiry=7d. Change the field to 1h, 24h, or 30d. Account configs can use 90d and 180d on Pro. Images are not kept forever.
