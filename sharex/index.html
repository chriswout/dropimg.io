DropIMG for ShareX

Capture. Upload. Link copied.

Import a one-file config. ShareX keeps capturing the way it already does. dropimg.io returns a temporary link — 7 days by default, or 1 hour / 24 hours / 7 days if you set the expiry field.

  • Windows. ShareX 15+
  • Anonymous config — no account
  • Account config attaches uploads to My drops
Download anonymous config Create an account config

Anonymous (no account)

  1. Download dropimg.sxcu and double-click it, or Import it in ShareX → Destinations → Custom uploader.
  2. Set dropimg.io as the image uploader destination.
  3. Capture as usual. The share URL is copied. Links default to 7 days and stay at 10 MB.

With a DropIMG account

  1. Sign in, open Integrations, and click Create ShareX config.
  2. Download dropimg-sharex.sxcu immediately — the token is shown once.
  3. Import that file. Uploads appear in My drops and use your plan's expiry options.

Expiry field

The public config sends expiry=7d. Change it to 1h or 24h for a shorter link. Pro account configs also accept 30d and 90d. Image passwords are not in the ShareX config.

If you lose the file

Revoke the old token on Integrations and create a new config. DropIMG cannot regenerate a previous token or .sxcu.
